# Inamori · Joyas que enamoran

App de control para la joyería Inamori: materiales y precios del día, catálogo con folios y fotos, etiquetas QR, catálogo en PDF, ventas, clientes y proveedores.

**Versión actual: V01** (16 de noviembre de 2026)

## Cómo se usa

Es un solo archivo, `index.html`. Se publica con GitHub Pages y se abre desde el celular en la dirección del sitio.

## Dónde viven los datos

La app se publica **sin datos**. Piezas, proveedores, clientes, ventas y fotos se guardan solo en el navegador del celular que la usa.

- Para no perder nada: pestaña Materiales, «Respaldo de tus datos», «Descargar respaldo».
- Para pasar los datos a otro celular: «Cargar respaldo» con ese archivo.
- Los archivos de respaldo **no se suben a este repositorio**: contienen costos y datos de clientes.

## Cómo se actualiza

Cada versión nueva reemplaza `index.html`. Los datos del celular se conservan porque la dirección del sitio no cambia.
